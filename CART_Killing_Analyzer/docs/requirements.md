# CAR-T 杀伤数据分析工具 — 需求规格

> 从 README.md 提取的正式需求，作为开发唯一真相源。

---

## FR-001 文件读取
- 上传 .xlsx / .xls 文件
- 自动搜索 A-H 行标签，定位 8×12 发光值矩阵
- 仅读取第一个 Sheet

## FR-002 96 孔板展示
- 8×12 Canvas 网格，每格显示取整后的发光值
- 行标签 A-H，列标签 1-12
- 悬停 Tooltip：位置 + 发光值（标注后追加细胞类型和 E:T）

## FR-003 孔位选择
- 单击选中
- Ctrl+单击多选
- Shift+单击连续区域选中
- 选中孔蓝色边框高亮
- 右侧面板实时显示已选孔列表

## FR-004 批量标注
- 细胞类型下拉框（预设：Control, A1-KO, 目的基因KO, 其他）+ 自定义输入
- E:T 下拉框（预设：0:1, 1:1, 5:1, 10:1, 20:1）+ 自定义输入
- tumor-only 复选框（勾选后类型和 E:T 置灰）
- 「应用」按钮批量写入选中孔

## FR-005 颜色编码
- 未标注：#FFFFFF
- tumor-only：#9CA3AF（灰色）
- Control：#F3F4F6（浅灰）
- A1-KO：#FECACA（浅红）
- 目的基因KO：#FED7AA（浅橙）
- 自定义类型：调色盘依次分配

## FR-006 配置存取
- 保存为 JSON（孔位置 → 标注信息）
- 加载 JSON 按位置匹配
- 越界孔忽略并提示
- 覆盖前检测已有标注并提示

## FR-007 分析计算
- T_only_mean = tumor-only 孔 RLU 的算术均值
- Killing(%) = (1 - RLU / T_only_mean) × 100
- 按「细胞类型 + E:T」分组统计均值 ± SD
- 至少 1 个 tumor-only 孔，否则弹窗报错

## FR-008 图表
- 主图：全细胞类型折线图，X=E:T，Y=杀伤率(%)，误差棒=SD
- 对比图：下拉框选两种细胞类型，同一坐标系对比
- 每个图表下方有「下载 PNG」按钮

## FR-009 数据导出
- 完整 CSV：孔位置、细胞类型、E:T、RLU、T_only_mean、杀伤率、组均值、组 SD
- 宽格式 CSV（可选）：行=细胞类型，列=E:T，值=杀伤率均值

## FR-010 打包
- PyInstaller 打包为单文件 .exe
- 无需用户安装 Python 环境
- 交付物：源码 + requirements.txt + 打包指南 + .exe
