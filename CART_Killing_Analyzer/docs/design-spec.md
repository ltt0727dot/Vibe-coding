# 设计规范

## 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色调 | #2563EB | 蓝色，按钮/选中高亮/标题 |
| 主色浅 | #DBEAFE | 鼠标悬停背景 |
| 背景 | #F8FAFC | 窗口背景 |
| 文字 | #1E293B | 深灰，主要文本 |
| 文字浅 | #64748B | 次要文本/标签 |

## 孔位颜色

| 标注类型 | 背景色 | 说明 |
|----------|--------|------|
| 未标注 | #FFFFFF | 白色 |
| tumor-only | #9CA3AF | 灰色 |
| Control | #F3F4F6 | 浅灰 |
| A1-KO | #FECACA | 浅红 |
| 目的基因KO | #FED7AA | 浅橙 |
| 自定义类型 | 调色盘 | 蓝绿紫系轮换 |

自定义类型调色盘（按分配顺序）：
1. #DBEAFE（浅蓝）
2. #D1FAE5（浅绿）
3. #EDE9FE（浅紫）
4. #FEF3C7（浅黄）
5. #CCFBF1（青绿）
6. #FCE7F3（浅粉）

## 选中高亮

- 边框色：#2563EB
- 边框宽度：2px
- 未选中：1px #D1D5DB 边框

## 字体

- 系统：微软雅黑（Windows 默认）
- 孔值字号：9pt
- 标签字号：10pt
- 标题字号：14pt bold

## 窗口

- 默认尺寸：1280 × 800
- 最小尺寸：1024 × 768
- 标题：CAR-T 杀伤分析工具

## 交互细节

- 孔位 hover：指针变为手型，显示 Tooltip（位置 + 细胞类型 + E:T + RLU）
- 已标注孔：显示半透明背景色，文字为发光值
- tumor-only 孔：灰度背景下显示 "T" 图标或文字标记
- 按钮 hover：背景色加深 10%
- 应用按钮：点击后短暂闪烁（200ms）表示生效
