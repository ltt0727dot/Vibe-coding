- # CAR-T 杀伤数据分析工具 - 项目需求文档

## 一、项目概述
开发一个用于 CAR-T 杀伤实验数据分析的exe软件，能够读取酶标仪导出的 96 孔板发光值（RLU），通过交互式界面标注细胞类型和效应靶比，自动计算杀伤率并生成图表。最终打包成一个 Windows 上可直接双击运行的 .exe 文件，无需用户安装 Python 环境。

## 二、输入文件格式
- 文件类型：Excel（.xlsx 或 .xls），由酶标仪导出，示例文件结构见文件中的xlsx文件。
- 数据特点：前若干行为元数据，中间某行开始出现 8 行 × 12 列的发光值矩阵，行标签为 A-H，列标签为 1-12。
- 要求：代码自动定位数据起始行（搜索包含 "A","B","C","D","E","F","G","H" 的行，且下一行为数字矩阵）。

## 三、用户界面与交互

### 3.1 整体布局
- 主色调为蓝色，风格简洁直观。
- 顶部：文件上传组件。
- 主区域：96 孔板网格展示（8行×12列），每个格子显示发光值（取整）。
- 右侧或底部区域：用于批量标注、配置保存/加载、分析控制。

### 3.2 96 孔板交互
- 支持**鼠标点击选择孔**：
  - 单击选中单个孔。
  - Ctrl + 单击 多选（或 Cmd + 单击）。
  - Shift + 单击 选择连续区域。
- 被选中的孔高亮显示（蓝色边框或背景色）。
- 每个孔可根据已标注的细胞类型显示不同背景色（例如 Control 灰色，KO 浅红，tumor-only 浅绿等），鼠标悬停显示详细信息（细胞类型、E:T、发光值）。

### 3.3 批量标注
- 显示当前选中的孔列表（如 "A1, B2, C3"）。
- 提供三个控件：
  - **细胞类型**：下拉框（预设：Control, A1-KO, 目的基因KO, 其他），并支持用户手动输入自定义类型（文本输入+添加按钮）。
  - **E:T 比例**：下拉框（预设：0:1, 1:1, 5:1, 10:1, 20:1），支持用户手动输入自定义比例。
  - **标记为 tumor-only**：复选框。
- **应用按钮**：将当前设置批量应用到所有选中的孔。
- 若某孔已被标记为 tumor-only，其细胞类型和 E:T 比例自动变为不可选（置灰），且这些孔不参与后续的分组分析和绘图（只用于计算分母）。

### 3.4 配置保存与加载
- **保存配置按钮**：将当前整个 96 孔板的标注信息（每个孔的细胞类型、E:T、是否 tumor-only）保存为一个 JSON 文件（用户选择保存路径）。
- **加载配置按钮**：加载之前保存的 JSON 文件，自动将标注应用到当前上传的 96 孔板（按孔位置匹配，如 A1 对应 A1）。若加载的配置中有孔位超出范围，忽略并提示。
- 可选：自动检测当前板子是否有已标注的孔，提示是否覆盖。

### 3.5 分析触发
- 提供 **“开始分析”** 按钮。点击后执行计算和绘图。
- 若未标记任何 tumor-only 孔，弹出错误提示：“请至少标记一个 tumor-only 孔作为归一化分母”。

## 四、计算逻辑

### 4.1 分母计算
- 收集所有被标记为 **tumor-only** 的孔，提取其发光值（RLU）。
- 计算这些发光值的**算术平均值**，记为 `T_only_mean`。
- 如果 tumor-only 孔数量为 0，则无法计算，提示错误。

### 4.2 杀伤率计算
- 对于 96 孔板中的**每一个孔**（包括 Control 孔和实验组孔），计算：
- Killing (%) = (1 - 该孔发光值 / T_only_mean) × 100
- 注意：发光值越低表示杀伤越强，杀伤率越高。

### 4.3 分组统计
- 按照 **细胞类型 + E:T 比例** 进行分组。
- 排除标记为 tumor-only 的孔。
- 对于每个分组：
- 若有多个重复孔（即相同细胞类型和相同 E:T 比例），计算杀伤率的**均值**和**标准差**。
- 若只有一个孔，标准差为 0 或 NaN，绘图时不显示误差棒（但仍显示点）。

## 五、图表输出

### 5.1 主图：所有细胞类型对比
- 折线图，X 轴为 E:T 比例（按数值排序，如 0:1, 1:1, 5:1, 10:1...），Y 轴为杀伤率（%）。
- 不同细胞类型用不同颜色的折线。
- 误差棒表示标准差（若该组重复数 ≥2）。
- 图标题、坐标轴标签清晰，图例在外。

### 5.2 对比图：用户选择两种细胞类型
- 增加两个下拉菜单（或一个多选但限制两个），让用户选择两种细胞类型（例如 A1-KO 和 目的基因KO）。
- 绘制这两种细胞类型的杀伤曲线（同一坐标系），其他要求同主图。

### 5.3 下载功能
- 每个图表下方提供 **“下载为 PNG”** 按钮。

## 六、数据输出（CSV）

### 6.1 完整数据表
提供 CSV 下载，包含以下列：
- 孔位置（如 A1）
- 细胞类型
- E:T 比例
- 原始发光值
- 全局分母（T_only_mean）
- 杀伤率（%）
- 组内均值（同一分组的杀伤率均值）
- 组内标准差

### 6.2 宽格式表格（可选）
- 生成一个适合直接粘贴到 GraphPad Prism 的表格：
- 行索引 = 细胞类型
- 列索引 = E:T 比例（按数值排序）
- 单元格值 = 该分组的杀伤率均值
- 提供下载（CSV 或 Excel）。
