# 需求规格文档

## 项目概述

**产品名称**：History Clipboard（历史剪贴板）

**一句话描述**：Windows 平台本地剪贴板历史管理工具，自动记录复制内容，支持随时回溯粘贴。

## 目标用户

普通 Windows 用户，无需任何技术背景，双击 exe 即可使用。

## 功能需求

### F1 - 自动记录剪贴板
- 后台监听 Windows 剪贴板变化
- 自动记录每次复制操作的内容
- 支持**文字**和**图片**两种类型
- 连续两次复制相同内容时不重复记录（去重）

### F2 - 历史面板展示
- 点击系统托盘图标弹出历史面板
- 以卡片形式展示所有记录
- 排列规则：
  - 置顶项优先展示（按置顶时间倒序）
  - 非置顶项按复制时间倒序（最新在上）
- 文字卡片：显示文本内容预览，最多 3 行
- 图片卡片：显示缩略图（60×60 px）

### F3 - 再次粘贴
- 点击任意卡片，将其内容复制回系统剪贴板
- 文字 → 直接写入剪贴板
- 图片 → 将图片文件写入剪贴板
- 复制成功后面板自动隐藏，用户回到目标应用 Ctrl+V 即可粘贴

### F4 - 置顶
- 每条记录可置顶
- 置顶项不受自动清理影响（永不过期）
- 可取消置顶

### F5 - 删除
- 每条记录可删除
- 图片记录删除时同步删除本地图片文件

### F6 - 搜索
- 顶部搜索栏，输入关键词实时过滤
- 仅对文字记录进行全文匹配
- 图片记录不受搜索影响（仍显示）

### F7 - 存储期限设置
- 提供三个选项：1天 / 3天 / 5天
- 默认 3 天
- 到期自动清理非置顶记录
- 每次启动时执行一次清理

### F8 - 系统托盘运行
- 最小化到系统托盘，不占据任务栏
- 左键点击托盘图标 → 弹出面板
- 右键托盘图标 → 菜单：打开面板 / 设置 / 退出

## 非功能需求

### N1 - 性能
- 面板弹出响应时间 < 300ms
- 500 条记录内滚动流畅

### N2 - 隐私
- 所有数据仅存储在本地
- 不上传任何网络
- 图片文件存储在本地应用数据目录

### N3 - 可靠性
- 剪贴板监听不能漏记录（轮询间隔 ≤ 500ms）
- 异常退出后数据不丢失（SQLite WAL 模式）

## 不做什么（范围外）
- 不支持文件复制记录
- 不支持云同步
- 不支持多设备协同
- 不支持 Markdown / 富文本格式保留
