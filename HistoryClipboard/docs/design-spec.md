# UI 设计规范

## 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#1890FF` | 蓝色，按钮、高亮、选中态 |
| 主色悬停 | `#40A9FF` | 按钮 hover |
| 主色点击 | `#096DD9` | 按钮按下 |
| 背景色 | `#F5F7FA` | 面板整体背景 |
| 卡片背景 | `#FFFFFF` | 卡片底色 |
| 浅蓝背景 | `#E8F4FD` | 置顶卡片背景 |
| 主文字色 | `#1F1F1F` | 标题、正文 |
| 次要文字 | `#8C8C8C` | 时间戳、辅助信息 |
| 边框色 | `#E8E8E8` | 卡片边框、分割线 |
| 危险色 | `#FF4D4F` | 删除按钮 |

## 字体

- 系统默认字体：Microsoft YaHei (Windows)
- 卡片正文：12px
- 时间戳：11px
- 标题：14px Bold

## 窗口规格

### 主面板
- 尺寸：380 × 520 px
- 圆角：12px
- 无边框窗口（FramelessWindowHint）
- 自定义标题栏（蓝色背景，白色文字）
- 窗口定位：屏幕右下角，托盘图标正上方

### 卡片
- 宽度：自适应（面板宽 - 16px padding）
- 高度：文字卡片自适应（最小 56px），图片卡片 80px
- 圆角：8px
- 边距：上下 4px，左右 8px
- 阴影：`0 1px 4px rgba(0,0,0,0.08)`（用 QGraphicsDropShadowEffect）
- 边框：1px solid `#E8E8E8`

### 置顶标识
- 左侧蓝色竖线（宽 3px，高与卡片等高，圆角）

### 搜索栏
- 顶部固定，高度 40px
- 圆角 20px（胶囊形）
- 背景 `#F5F5F5`
- 左侧搜索图标，灰色文字 placeholder

### 设置对话框
- 模态对话框，尺寸 300 × 200 px
- 居中显示
- 下拉选择：1天 / 3天 / 5天
- 确定 / 取消 按钮

## 交互行为

- 点击卡片 → 复制内容 → 面板自动隐藏（300ms 后）→ 状态栏短暂提示"已复制"
- 置顶按钮：卡片右上角图钉图标，点击切换置顶/取消
- 删除按钮：卡片右上角垃圾桶图标，点击后卡片淡出移除
- 搜索：输入即时过滤，无结果时显示空状态"无匹配记录"
- 滚动：鼠标滚轮，平滑滚动
- 面板失焦自动隐藏（点击面板外部区域）

## 图标

使用 Unicode 符号代替图标文件，避免引入图标库依赖：
- 置顶（未置顶）：`⋮` 或 `📌`
- 置顶（已置顶）：`📌`（蓝色）
- 删除：`✕` 或 `🗑`
- 搜索：`🔍`
- 托盘图标：需要一个 .png 图标文件（蓝色方形剪贴板图案）
